*--- Fetch CRAC details from CPI over HTTP (was: sproxy si_cracsummary_ob) ---*
*  Map sproxy request fields -> CPI/GeM API JSON (method getCrac):
*    client_code -> user, userid -> buyer_user_id,
*    datefrom/dateto -> from_date/to_date (YYYYMMDD -> YYYY-MM-DD),
*    token -> HTTP header (Bearer).
