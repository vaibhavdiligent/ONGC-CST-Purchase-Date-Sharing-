*--- Fetch data from CPI over HTTP (was: sproxy call si_order_count_ob) ---*
*  Map the sproxy request fields to the CPI/GeM API JSON request:
*    sproxy client_code -> api user           (integration/client account)
*    sproxy userid      -> api buyer_user_id  (buyer GeM user id)
*    sproxy datefrom    -> api from_date       (reformatted YYYYMMDD -> YYYY-MM-DD)
*    sproxy dateto      -> api to_date         (reformatted YYYYMMDD -> YYYY-MM-DD)
*    sproxy requesttype -> replaced by api method
*    sproxy token       -> sent as HTTP header (Bearer), not in body
      CLEAR ls_cpi_req.
      ls_cpi_req-user          = order_count-mt_order_count_s_req-client_code.
      ls_cpi_req-method        = 'orderCount'.

      CONCATENATE order_count-mt_order_count_s_req-datefrom+0(4)

      CONCATENATE order_count-mt_order_count_s_req-dateto+0(4)
                  order_count-mt_order_count_s_req-dateto+4(2)
                  order_count-mt_order_count_s_req-dateto+6(2)

        lo_http->request->set_method( if_http_request=>co_request_method_post ).
        lo_http->request->set_header_field( name = 'Content-Type' value = 'application/json' ).
        lo_http->request->set_header_field( name = 'token' value = |Bearer { token }| ).
        lo_http->request->set_cdata( lv_json_req ).
        lo_http->send( EXCEPTIONS OTHERS = 1 ).
        IF sy-subrc = 0.

          lo_http->response->get_status( IMPORTING code = lv_http_code reason = lv_http_reason ).

        ENDIF.
        lo_http->close( EXCEPTIONS OTHERS = 0 ).
      ENDIF.
